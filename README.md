# 装机助手

一个**离线**的 Windows 装机工具箱，帮你快速配置环境。双击就能用、不用装 Python，把新电脑从「刚装完系统」快速配成「能写代码、能正常用」的状态。

> 作者：NDCC ｜ 纯 Python 3.7 + Tkinter 写的图形界面程序，有 Win7 适配

---

## 这个软件是做什么的

给 Windows 电脑做四件事：**装开发环境、优化系统、检测硬件、诊断问题**。

---

## 能干什么

### ① 装开发环境（离线一键装 / 卸）

Python、C/C++（GCC）、Java（JDK）、Node.js、Git、VS Code，每个都分两个版本：

| 软件 | 给老电脑（Win7） | 给新电脑（Win10/11） |
|------|-----------------|---------------------|
| Python | 3.8.10 | 3.13.15 |
| C/C++ | GCC（MSVCRT 运行时） | GCC（UCRT 运行时） |
| Java | JDK 8 | JDK 21 |
| Node.js | 13.14.0 | 26.10.0 |
| Git | 2.46.2 | 2.55.0.5 |
| VS Code | 1.85.2 | 1.139.0 |

> 为什么分两个版本？因为很多新版本软件已经**不再支持 Win7**。这个工具帮你选对版本——老电脑装老的，新电脑装新的。

特点：

- **点一下装好**，自动配好 PATH（不用手动改环境变量）
- **防篡改**：每个安装包都内置 SHA-256 指纹，安装前先校验，文件被人改过就拒绝装
- **卸载也一键**：Python 支持选版本卸载（多版本共存时只卸指定的那个）
- 单版本软件（C/C++、Java）装第二个时会明说「不能同时装两个，先卸旧的再装」

### ② 优化系统

- 暂停 / 恢复 Windows 自动更新（不用怕更新重启打断你）
- 显示文件扩展名、显示隐藏文件
- 清理临时文件、清空回收站
- 把「下载 / 桌面 / 文档」挪到 D 盘（C 盘不再爆满）

### ③ 检测硬件

CPU、显卡、屏幕分辨率、屏幕尺寸和色域、显卡运行模式，一键看清这台电脑什么配置。

### ④ 诊断问题

显卡/屏幕、设备驱动、内存/硬盘三类问题，点一下给结论，还有「一键诊断」汇总。

> 危险操作（清回收站、挪文件夹、配远程桌面）执行前都会先弹窗提醒后果，不会闷头就做。

## 怎么用

1. 拿到一个 zip 压缩包，里面有两样东西：
   - `Toolbox.exe`（主程序）
   - `packages\`（安装包文件夹）
2. 解压到任意地方，**双击 `Toolbox.exe`** 就能用。
3. 想装哪个软件，点对应按钮 → 选版本 → 装好。

> 注意：`Toolbox.exe` 和 `packages\` 文件夹**必须在同一个目录**，程序才能找到安装包。桌面快捷方式不影响（程序会自动定位真实路径）。

## 自己改怎么办

### 目录结构

```
装机助手/
├── src/            # 源码（main.py 主程序，hashes.py 安装包指纹）
├── rdpwrap/        # 远程桌面组件（rdpwrap.dll + ini）
├── Toolbox.spec    # 打包配置（PyInstaller）
├── build_hashes.py # 生成安装包指纹
├── 启动.bat         # 不打包时直接跑源码用
└── packages/       # 安装包（不入库，太大，自己从官网下）
```

### 重新打包

```bash
# 1. 换过安装包才需要：重新生成指纹
python build_hashes.py

# 2. 打包成 exe
python -m PyInstaller Toolbox.spec --noconfirm

# 3. 产物在 dist\Toolbox.exe
```

> 打包环境：Python 3.7.9 + PyInstaller 5.13.2（用 3.7 是为了兼容 Win7）。
